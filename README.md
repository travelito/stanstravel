# Karvon — MVP туристического сайта

Это рабочая версия сайта на Next.js. "Karvon" — временное название,
замените на своё в файле `lib/dictionary.ts` (поле `siteName`) когда
определитесь с брендом.

## Что уже решено (в отличие от старого сайта на Lovable)

- **Сервер сразу отдаёт полный HTML** — весь текст, заголовки, ссылки
  видны краулеру без выполнения JavaScript. Это главная проблема,
  из-за которой Яндекс плохо индексировал jamtrips.com.
- **Настоящий 404** — несуществующие страницы не показывают контент
  главной страницы (см. `app/not-found.tsx`).
- **Sitemap генерируется из реальных данных** (`app/sitemap.ts`) —
  битых ссылок в принципе быть не может, потому что список URL
  берётся из того же файла, что и сами страницы.
- **RU/EN переключение через отдельные URL** (`/ru/...`, `/en/...`)
  с `hreflang` — обе версии самостоятельно индексируются.
- **Уникальные title/description/canonical на каждой странице**,
  генерируются автоматически из данных тура.

## Фото и видео — как правильно загружать

**Никогда не кладите фото/видео прямо в код/GitHub** — сайт станет
медленным, а бесплатный Vercel быстро упрётся в лимиты.

- **Фото**: загружаются в Supabase Storage (после подключения Supabase),
  сайт берёт их по ссылке. Компонент `<Image>` в Next.js уже сам сжимает,
  меняет размер под экран и лениво подгружает — ничего дополнительно
  настраивать не нужно.
- **Видео**: не хранится на сайте вообще. Загружайте на YouTube (можно
  "по ссылке"/unlisted, чтобы не светилось в общем поиске YouTube) —
  и вставляйте через готовый компонент `components/VideoEmbed.tsx`,
  указав ID видео из ссылки YouTube. YouTube берёт на себя всю нагрузку
  по трафику и скорости — сайт от этого не тормозит.

## Как всё устроено (без технического жаргона)

- Все туры и экскурсии — в файлах `lib/data/tours.ts` и
  `lib/data/excursions.ts`. Чтобы добавить новый тур, достаточно
  скопировать один блок в этом файле и поменять текст — новая
  страница появится сама, без правки остального кода.
- Переводы интерфейса (кнопки, заголовки меню) — в
  `lib/dictionary.ts`.

## Как выложить сайт (шаг за шагом)

1. **GitHub**: создайте новый репозиторий на github.com → загрузите
   туда все эти файлы (кнопка "uploading an existing file" в
   интерфейсе GitHub, либо через git, если умеете).
2. **Vercel**: зайдите на vercel.com → "Add New Project" → выберите
   этот репозиторий → Vercel сам определит, что это Next.js, и
   нажмёте "Deploy". Через пару минут сайт будет жить на адресе вида
   `karvon.vercel.app`.
3. **Свой домен**: в настройках проекта на Vercel → Domains →
   добавьте свой домен, следуйте инструкции по DNS (это тот же
   процесс, что вы уже проходили с jamtrips.com).
4. **Важно**: после того как узнаете финальный домен, замените
   `https://example-karvon.com` на настоящий адрес в двух файлах:
   `app/sitemap.ts` и `app/robots.ts`, и в `app/[locale]/layout.tsx`
   (переменная `siteUrl`).

## Дальнейшее редактирование

- **Через Lovable**: импортируйте этот GitHub-репозиторий как новый
  проект в Lovable — дальше редактируете текстами/промтами как
  привыкли.
- **Через Claude Code** (входит в ваш Pro-план): подключаете к тому
  же репозиторию, просите правки обычным текстом — код сам
  обновляется и пушится в GitHub, Vercel передеплоивает автоматически.

## Что дальше (не входит в этот MVP)

- Подключение Supabase вместо статических файлов с турами (когда
  туров станет много и захотите менять их без правки кода).
- Голосовой AI-помощник — отдельный этап, обсудим когда сайт будет
  запущен и стабилен.
